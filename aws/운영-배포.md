## batch
1. batch_exe에서 시간이 되면 api서버에 인스턴스를 켜주세요 호출을 한다. api서버는 script/ start.sh 를 실행시키고 batch_timer_plan 에 값을 생성후 id를 받는다.
    1. 시작스크립트: ec2인스턴스의 설정값(사용자 데이터)을  batch_timer_plan.id의 값으로 수정 후 전원을 킨다.
    2. 종료할때는  app-batch는 user-data에있는 값으로 배치조건과 batch_timer_plan.id를 얻는다. 배치를 완료 후에 id로 batch_timer_plan의 상태를 종료로 수정한다.
3. 인스턴스가 켜지면 script 자동 실행한다.
   1. script 는 ecr 에시서 최신 이미지를 불러오고 컨테이너를 실행킨다.
   2. 컨테이너는 batch를 실행시키고 batch가 마무리 되면 api서버에 종료호출을 한다.
   3. api 종료호출을 받으면 api서버는 인스턴스를 종료스크립트를 호출한다.
   4. 인스턴스가 종료된다.
4. 배포는 ecr 에 넣기 까지만.
